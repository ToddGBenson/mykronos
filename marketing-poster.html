MYKRONOS

Register a repository. Fifteen checks run. One engine decides.

Onboard any GitHub repo and Mykronos installs the pipelines, runs the standard set of security and quality checks, lands every result in a local data lake, and puts it through a risk-decision engine that returns a verdict — not another list of findings for somebody to triage.

The components

Six services behind one dashboard
Oracle
Risk decision engine

The adviser and the gate. Publishes a path to green and a shadow report before it ever starts blocking.

Aegis
Insider risk

The PR gate for AI authorship and privilege-adjacent change. States plainly whether it blocks.

Atlas
Supply chain · SCA

Dependency and licence compliance, SBOM download, and a freshness signal that is actually measured.

Patchwork
Auto-remediation

Generates the fix PR from the finding, previews the diff, and learns from a rejected fix.

JDED
Unified dashboard

Portfolio scoring across every repo, drilling into an eight-tab page per repository.

Knowledge
RAG learning

Retro feedback captured across repos, so false positives and recurring issues get recognised.

What it does not claim

Stated on the poster, not buried in a footnote
Known limits · carried in the docs as decisions
No reachability engine
Exploitability is reported as unknown rather than guessed. Real call-graph analysis is separate work.
DAST is paused
Platform-wide, until the scan has a resource budget. Built, wired, deliberately off.
Network awaits a CIDR
Shipped and idle until there is a range the operator is authorised to scan.
Threat model is capability-level
STRIDE across capabilities, not per-CWE — no finding carries a structured CWE yet.
